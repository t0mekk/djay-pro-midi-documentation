Touch controls on the hardware to add them, or edit the JSON. Click a tile to label it.
Format
  • rows is a list; each row is a list of controls, drawn left to right.
  • A control is text: "pot 4", "fader 16 Volume", "enc 0 Browse", "btn 36 Play" — kind, number, optional label. Buttons are notes and the rest CC unless you say "btn cc12" / "pot n5". Add @16 for a control on its own channel. "-" leaves a blank cell.
  • Or an object for extras: {"type":"btn","note":12,"label":"Layer","led":4,"w":2} (w = width in cells).
  • "gap" adds space, "# Mixer" a heading.
  • channel (1-16) is the device channel. decks lists the deck of each column, e.g. [1,2,3,4]; a row written as {"decks":false,"cells":[…]} ignores it.
  • led: note offset for extra LED colours (colour 2 at note+led, colour 3 at note+2×led). device, usbId and match (regex on the device name) are used for new files and on import.
